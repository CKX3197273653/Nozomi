# 缺陷判定与处理规则

## 1. 判定原则

- **裂纹类**：零容忍，任何可见裂纹均判不合格
- **安全件**（转向节、制动钳、刹车盘）：判定从严，不允许返修后放行
- **一般件**：依据超差程度选择返修或报废
- **数据缺失时**：转人工测量，不做推测判定

## 2. 处理建议对照表

| 缺陷类型 | 处理建议 | 备注 |
|---|---|---|
| 划痕 | 抛光处理 | 超差严重时报废 |
| 裂纹 | 报废或焊接修复 | **安全件必须报废** |
| 色差 | 重新喷涂 | 不影响功能可让步接收 |
| 变形 | 校正或更换 | 同轴度超差需评估 |
| 气孔 | 视位置和大小 | 影响密封/油路判报废 |
| 砂眼 | 报废 | 油道砂眼影响油压 |
| 缩松 | 评估强度后决定 | 局部轻微可让步 |
| 锈蚀 | 除锈后重新检验 | 装配部位从严 |
| 毛刺 | 去毛刺后复检 | |
| 油渍残留 | 清洗后复检 | |
| 标识不清 | 重新打标 | |
| 尺寸超差 | 返修或报废 | 视超差量与功能影响 |
| 加工残留（碎屑） | 清理后复检 | 油道内残留必须清理 |

## 3. 严重等级定义

| 等级 | 中文 | 定义 | 典型场景 |
|---|---|---|---|
| CRITICAL | 致命 | 影响安全，可能导致断裂/失效 | 安全件裂纹、贯穿性裂纹 |
| HIGH | 严重 | 影响功能，必须处理 | 漏水/漏油风险、运动干涉 |
| MEDIUM | 一般 | 影响装配或外观一致性 | 尺寸超差、锈蚀、毛刺 |
| LOW | 轻微 | 影响轻微，可让步接收 | 局部油渍、轻微色差 |

## 4. 升级规则

- 同一报告出现 ≥ 3 个缺陷 → 严重等级升级一级
- 出现 ≥ 2 处裂纹 → 触发批次追溯
- 关键尺寸超差 → 触发全检
