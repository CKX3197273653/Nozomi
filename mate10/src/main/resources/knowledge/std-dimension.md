# 尺寸与重量检测标准

## 1. 通用尺寸公差

| 检测项 | 公差范围 |
|---|---|
| 长度 | ±0.05mm |
| 宽度 | ±0.03mm |
| 高度 | ±0.02mm |

## 2. 重量公差
- 单件重量公差：**±5%**

## 3. 孔类尺寸

| 检测项 | 判定 |
|---|---|
| 主销孔内径 | 超出公差上限 0.03mm 判不合格 |
| 活塞孔直径 | 超差 0.05mm 判不合格（影响配合） |
| 螺栓孔螺纹 | 螺纹不完整（缺牙、乱牙）判不合格 |

## 4. 形位公差

| 检测项 | 要求 | 超差影响 |
|---|---|---|
| 同轴度 | 主轴承座同轴度超差判不合格 | 装配偏心、异常磨损 |
| 端面跳动 | 制动面跳动 > 0.08mm 判不合格 | 制动抖动 |
| 厚度均匀性 | 摩擦面厚度偏差 > 0.15mm 判不合格 | 制动性能下降 |

## 5. 尺寸超差的处理
- 超差量 ≤ 公差上限的 20%：评估后返修
- 超差量 > 公差上限的 20%：报废
- 影响配合/密封功能的尺寸，一律从严判定
