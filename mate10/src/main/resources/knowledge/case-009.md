# 案例：制动钳油道内部金属碎屑残留

- **案例编号**：CASE-009
- **缺陷类型**：加工残留
- **产品/批次**：制动钳 / B20260810C1
- **产线**：制动产线
- **报告编号**：R20260810002
- **检验员/时间**：小张 / 2026-08-10
- **严重程度**：一般

## 现象描述
油道内有金属碎屑残留。

## 生产参数
浇注温度 1495°C、压力 116MPa、湿度 55%、速度 30rpm。

## 判定结论
**不合格**。油道碎屑会污染制动液、堵塞阀孔。

## 处理建议
清洗后复检；清洗不彻底则报废（**油道内部残留必须清理干净**）。

## 根因分析
机加工后清洗工序不到位，或清洗液压力不足。
