# 外观检测标准

适用范围：铸件、锻件及机加工件的外观质量检验。

## 1. 划痕
- **判定标准**：深度 ≤ 0.1mm 且长度 ≤ 5mm 为合格
- **超差判定**：深度 > 0.1mm 或长度 > 5mm 判不合格
- **典型位置**：外圆面、缸盖贴合面、密封槽
- **测量工具**：深度千分尺、游标卡尺
- **处理建议**：抛光处理；超差严重时报废

## 2. 裂纹
- **判定标准**：任何可见裂纹均为不合格（零容忍）
- **典型类型**：贯穿性裂纹、疲劳裂纹、热应力裂纹、水套壁裂纹
- **典型位置**：壳体侧壁、转向节根部、缸体水套壁
- **危害**：影响结构强度、存在断裂风险、可能导致漏水/漏油
- **处理建议**：报废；安全件必须报废并追溯同批次

## 3. 色差
- **判定标准**：ΔE 值 < 2.0 为合格
- **检测方法**：与标准样板目视对比 + 色差仪测量
- **典型位置**：壳体表面
- **处理建议**：重新喷涂；不影响功能可让步接收

## 4. 变形
- **判定标准**：扭曲度 ≤ 0.5mm 为合格
- **衍生指标**：同轴度、平行度、平面度
- **危害**：导致装配卡滞、运动干涉
- **处理建议**：校正或更换

## 5. 铸造类缺陷
- **气孔**：表面气孔直径 ≤ 2mm 可接受；多处气孔或影响功能判不合格
- **砂眼**：任何影响油路/水路的砂眼判不合格
- **缩松**：局部缩松面积 ≤ 10mm² 且不影响强度为轻微

## 6. 表面处理类
- **锈蚀**：螺纹等装配部位出现锈蚀判不合格
- **毛刺**：装配面、密封面边缘不允许有毛刺
- **油渍残留**：影响外观或后续工序的油渍判轻微
- **标识不清**：激光打标字符不可识别判不合格
