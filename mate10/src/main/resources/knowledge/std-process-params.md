## 3. 关键结论

1. **温度是主导因素**：所有含缺陷的报告，温度均高于同产品合格基线 **15°C 以上**；
   缺陷数量与温度呈正相关。
2. **温度超标幅度与严重等级相关**：
    - 超标 > 50°C → 严重（发动机缸体 1540°C、转向节 1520°C）
    - 超标 20~50°C → 一般至严重
    - 超标 < 20°C → 轻微至一般
3. **变速箱壳体产线需重点关注**：该产线 3 份报告**全部含缺陷**，
   且参数已接近其他产品的正常区间（1462~1485°C）仍有缺陷——
   说明该产品的温度控制窗口需要**重新标定**。

## 4. 建议控制线

- 浇注/锻造温度控制在合格基线 **±10°C** 内
- 湿度控制在 **42~50%**，超过 55% 需预警
- 速度偏离基线 **±2 rpm** 时需检查设备状态
